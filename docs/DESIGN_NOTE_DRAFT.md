# Design note

**DRAFT — Creed to edit in his own words before any sharing.**

I started The Pitch Index because youth soccer families make big decisions (which club, which league, which team) with almost no honest information about how strong a team really is. League standings only compare teams inside one conference, and most national rankings do not show their work.

So the rule for this project is simple: results only, one published formula, and every game on the record. If someone disagrees with a ranking, they can rerun it themselves.
