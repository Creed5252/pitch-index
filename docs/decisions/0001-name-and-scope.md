# 0001 – Name and scope

Date: 2026-11-19 (decided in chat with Creed)

- Name: **The Pitch Index**.
- Every elite league at once, boys and girls, U11–U19 where played. No soft rollout league by league.
- Rankings are strength-of-schedule based and include national qualifiers, showcases and cross-division games.
- Each league is segmented by its own structure (conferences, regions, districts).
